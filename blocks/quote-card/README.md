# quote-card

Custom **quote** block. Purpose: Thin-bordered box with serif quotation and small uppercase attribution with leading dash.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: quotation paragraph; row 2 (optional): attribution paragraph (dash is added automatically).
