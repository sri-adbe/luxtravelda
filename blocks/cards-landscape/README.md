# cards-landscape

Custom **cards** block. Purpose: Frameless 2-up grid of large rounded landscape images with country eyebrow, title and one-line description.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1 landscape image; cell 2 country eyebrow paragraph, H3 title (optionally linked to a detail page), description paragraph.
